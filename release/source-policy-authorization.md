# First experimental release source-policy authorization

The maintainer authorized the source-policy decisions for the frozen canonical
corpus in the coding-agent session on 2026-09-14:

> I authorize the first experimental release with the source licenses recorded
> below.

The release may materialize source-derived records only under the applicable
upstream terms:

- Async-TN: Apache-2.0; source text may be embedded with the license notice and
  source attribution preserved.
- PolyNorm: CC BY-NC-ND 4.0; the release uses external references so it does not
  share adapted material. Any future verbatim redistribution must remain
  noncommercial and retain attribution, license, disclaimer, and source link.
- Proteno and its language shards: CC BY-NC 4.0; source text may be embedded,
  with noncommercial use, attribution, and modification notices preserved.

The release includes the upstream license evidence files under `release/licenses/`
and preserves source identity, revision, hashes, and license metadata. This
authorization applies to the experimental local release only. It does not
authorize a Git tag, remote push, public publication, or completion of missing
upstream ingestion.
